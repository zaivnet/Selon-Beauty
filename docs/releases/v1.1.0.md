## Overview

Version 1.1.0 introduces **Outlet Mode Foundation**, enabling organizations to operate the platform in either **Single Outlet** or **Multi Outlet** mode without altering the underlying unified database architecture.

- **Single Outlet Mode**: Streamlines the user interface by hiding redundant multi-branch filters, selectors, and transfer controls. Automatically binds new employees to the single active operational outlet.
- **Multi Outlet Mode**: Provides full multi-branch management, cross-outlet duty rosters, temporary schedule overrides, and permanent transfers.

## Upgrade Instructions (Existing v1.0.0 Installation)

Follow this standardized procedure when upgrading from v1.0.0 to v1.1.0:

1. **Preserve Environment & Configuration**: Ensure `.env` and `APP_KEY` remain unchanged.
2. **Preserve Production Database**: The existing database must remain untouched with zero data resets.
3. **Preserve Private Media**: Private selfie evidence, leave attachments, and branding files must remain in storage.
4. **Create Pre-Upgrade Safety Backup**:
   ```bash
   /home/<user>/bin/php84-attendance artisan app:run-scheduled-backup
   ```
5. **Deploy v1.1.0 Release Code**:
   ```bash
   git fetch --tags
   git pull --ff-only origin main
   ```
6. **Execute Migration Check**:
   ```bash
   /home/<user>/bin/php84-attendance artisan migrate --force
   ```
   *(Expected: Zero new schema migrations for Outlet Mode)*
7. **REQUIRED: Initialize Operational Mode**:
   ```bash
   /home/<user>/bin/php84-attendance artisan app:init-outlet-mode
   ```
   *(For an existing 2-outlet production installation, output will report: `Outlet mode initialized: multi (2 active outlets detected)`)*
8. **Rebuild Application Caches**:
   ```bash
   /home/<user>/bin/php84-attendance artisan optimize:clear
   /home/<user>/bin/php84-attendance artisan config:cache
   /home/<user>/bin/php84-attendance artisan route:cache
   /home/<user>/bin/php84-attendance artisan view:cache
   ```
9. **Perform Post-Upgrade Smoke Verification**:
   - Verify administrative login.
   - Verify attendance monitoring and geofence evaluation.
   - Verify outlet mode configuration under Attendance Settings.
